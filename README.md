Overview

This project presents an interactive Customer Cohort & Retention Analysis Dashboard developed using Power BI.
The dashboard analyzes customer behavior over time by grouping customers into cohorts based on their first transaction month and tracking their retention, churn, and reactivation patterns.

It provides end-to-end visibility into the customer lifecycle, helping businesses understand how customer engagement evolves across months.

Project Purpose

The purpose of this dashboard is to help business stakeholders, marketing teams, and analysts:

Understand customer retention and churn behavior

Track cohort-wise performance over time

Identify resurrected (reactivated) customers

Measure long-term customer engagement and lifecycle trends

Support data-driven decisions to improve retention strategies

Tech Stack

Power BI – Data modeling, DAX calculations, interactive dashboards

Power Query – Data cleaning, transformation, and date intelligence

Excel / CSV – Source data format

DAX Measures – Cohort size, retained, lost, resurrected customers

Data Source

Simulated / Sample retail transaction data (SuperStore style dataset)

Dataset includes:

Customer ID

Order Date

Transaction history

Time dimensions (Year, Month, Week)

Note: This dashboard uses sample data for learning and portfolio demonstration purposes.

Business Problem

Many businesses acquire customers but struggle to understand:

How long customers stay active after acquisition

When and why customers churn

Whether lost customers return over time

Which acquisition periods generate long-term value

Without cohort-based analysis, customer behavior trends remain hidden.

Dashboard Goals

Group customers into monthly cohorts based on first purchase

Track retention performance across 24 months

Identify new, retained, lost, and resurrected customers

Analyze monthly customer lifecycle trends

Provide actionable insights to improve customer retention

Key Dashboard Features / Highlights

Monthly cohort matrix with 24-month retention tracking

New, retained, resurrected, and lost customer classification

Monthly trends analysis for customer lifecycle movements

Interactive slicers for date ranges and trend views

Clean and intuitive layout for business storytelling

Key Visuals & Why They Were Used
Cohort Matrix (Heatmap)

Used to visualize customer retention patterns across months, making it easy to compare cohort performance over time.

Stacked Column Chart (Monthly Trends)

Displays the relationship between new, retained, and resurrected customers to understand customer lifecycle dynamics.

Area Chart (Lost Customers Trend)

Helps identify churn patterns and periods with high customer loss.

Line & Area Charts (Retention & Resurrection Trends)

Used to track customer reactivation and long-term engagement behavior.

Key Insights

Early cohorts show stronger long-term retention compared to later cohorts

Customer churn tends to increase after specific lifecycle periods

Resurrected customers contribute significantly during certain months

Retention stability improves when customer acquisition is consistent

Conclusion

This Customer Cohort Analysis Dashboard transforms raw transactional data into meaningful customer insights.
It demonstrates how Power BI and DAX can be used to analyze customer lifecycle behavior, retention, churn, and reactivation patterns—key components for data-driven growth strategies.
